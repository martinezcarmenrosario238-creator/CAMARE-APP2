# CARMARÉ - proyecto inicial

Este es un proyecto Android nativo inicial en Kotlin y Jetpack Compose.

## Estado
- Pantalla inicial y navegación visual básica.
- Es una base de desarrollo, NO un APK instalado ni una versión terminada.
- Aún faltan las funciones completas, persistencia de datos, alarmas reales, inicio de sesión Google y sincronización en la nube.

## Compilación
Requiere Android Gradle Plugin 8.7.3, Gradle compatible y JDK 17.
La compilación se configurará en GitHub Actions en el siguiente paso.
